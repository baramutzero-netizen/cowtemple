# 소 귀에 경 읽는 절 (牛耳讀經寺)

말 대신 목탁을 치는 온라인 절입니다. 동자승이 되어 마당을 걷고, 방석에 앉아 목탁을 치면 경 한 글자가 날아가 소의 한쪽 귀로 들어갔다가 반대쪽 귀로 빠져나갑니다.

- **바로 들어가기:** https://baramutzero-netizen.github.io/cowtemple/
- 채팅은 없습니다. 합장, 절(108배 세기), 목탁만 있습니다.
- **법당(기본 채널):** 1번, 2번… 한 법당에 24명, 방석 16개이고, 차면 다음 번호 법당으로 들어갑니다.
- **발원 법당(직접 여는 채널):** 쾌유 기원, 합격 기원, 가족 평안, 추모·명복, 감사, 직접 쓰기 중에서 고르고 20자 문구를 씁니다(예: "어머니 수술이 잘 되기를").
  - 정원 2·4·8·16명(기본 8명). 정원에 맞춰 방석 수가 바뀝니다. 2명이면 둘이 나란히 앉는 법당이 됩니다.
  - 목록에 공개하거나, 초대 링크로만 들어오게 할 수 있습니다.
  - 아무도 없으면 하루 또는 일주일 뒤 저절로 닫힙니다. 연 사람은 그 브라우저에서 바로 닫을 수도 있습니다.
  - 현판 자리에 발원 문구가 걸리고, 목탁 108번마다 처마에 연등이 하나씩 늘어납니다.
  - 쾌유·추모 법당은 조용한 법당입니다. 소들이 농담을 하지 않고, 경은 소 귀가 아니라 연등 쪽 하늘로 올라갑니다.
  - 문구는 20자까지이고 링크, 전화번호 같은 긴 숫자, 욕설과 혐오 표현을 막습니다. 하루에 3개까지 열 수 있고, 신고가 3번 쌓이면 목록에서 숨겨집니다.
- **옵션(⚙):** 승복 색 6가지, 목탁 소리 9가지(소 귀에 경 읽기의 기본·목탁 1·2·3 녹음 그대로, 그리고 맑은 목탁, 큰 목탁, 대나무 딱따기, 싱잉볼, 8비트). 바꾸면 같은 법당 사람들에게도 그 색과 그 소리로 보이고 들립니다.
- 화면 위에는 오늘 이 절 전체에서 친 목탁 수, 소 귀에 들어간 경의 글자 수, 남은 경(언제나 0자)이 나옵니다.
- 서버에 연결되지 않으면 연습 동자승들과 함께하는 연습 모드로 열립니다.
- 소들과 목탁스님은 [소 귀에 경 읽기](https://baramutzero-netizen.github.io/moktak/)의 그 소들과 그 스님입니다.

## 조작

- 방석을 누르면 걸어가서 앉습니다. 마당을 누르면 그쪽으로 걷습니다(방향키/WASD도 됨).
- 앉아 있을 때: 목탁(스페이스바, 또는 내 방석 다시 누르기), 절(B), 합장(H).

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 완성된 페이지 한 파일 (GitHub Pages로 그대로 공개) |
| `client/game.src.html` | 페이지 소스 |
| `assets/` | 소와 목탁스님 도트 (소 귀에 경 읽기에서 가져옴) |
| `tools/build.py` | 글꼴을 쓰는 글자만 잘라 넣고, 그림과 서버 주소를 넣어 `index.html`을 만듦 |
| `server/` | 실시간 서버 (Cloudflare Workers + Durable Objects) |

## 서버 올리기 (처음 한 번)

Node.js가 필요합니다.

```bash
cd server
npm install
npx wrangler login      # 브라우저가 열리면 Cloudflare 계정으로 로그인
npx wrangler deploy     # 끝나면 https://cowtemple.<계정이름>.workers.dev 주소가 나옴
```

나온 주소를 페이지에 넣습니다. `index.html`에서 `const SERVER = ... || "";` 줄의 `""` 안에 주소를 넣거나, 다시 빌드합니다.

```bash
GALMURI=경로/package/dist python3 tools/build.py https://cowtemple.<계정이름>.workers.dev
```

주소 뒤에 `?server=주소`를 붙여 열면 빌드 없이도 시험해 볼 수 있습니다.

### 메타모아 접속자 수 보내기 (선택)

메타모아에 등록하고 공간 키를 받았다면, 키는 코드에 적지 말고 서버 비밀값으로만 넣습니다. 넣으면 10분마다 지금 접속자 수(숫자 하나)만 보냅니다.

```bash
npx wrangler secret put METAMOA_KEY     # mm_live_… 키
npx wrangler secret put METAMOA_SPACE   # 공간 id
```

## 개인 정보

로그인도 채팅도 없습니다. 서버는 접속한 동안만 임의 번호로 사람을 구분하고, 법당별 지금 인원과 목탁·절·합장 횟수의 합계, 발원 법당의 종류·문구·정원만 저장합니다. 누가 무엇을 했는지는 남기지 않습니다. 발원 법당 하루 3개 제한과 중복 신고 방지를 위해, 접속 주소는 그날만 쓰는 일방향 암호(해시)로 바꿔 그날 하루만 셉니다. 발원 법당을 닫는 열쇠는 연 사람의 브라우저에만 있습니다.
